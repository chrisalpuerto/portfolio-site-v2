## Anti-AI-Slop Design Rules

Do not default to common AI-generated design conventions.

Avoid:

* purple/blue gradients as a default palette
* gradient text
* glowing or blurred background orbs
* decorative glassmorphism
* Inter/Geist/Space Grotesk simply because they are safe defaults
* centered hero + subtitle + two CTA buttons as the automatic hero structure
* pill badges above headings
* repetitive 3-card or 6-card feature grids
* bento grids unless the information hierarchy actually calls for one
* putting every piece of content inside a rounded card
* nested cards
* excessive rounded-xl/rounded-2xl containers
* generic drop shadows on every container
* thick colored left-border cards
* rounded-square icon tiles above every feature heading
* excessive Lucide icons
* fake metrics, fake social proof, or decorative charts
* generic SaaS copy such as "Supercharge your workflow," "Unlock your potential," "Transform the way you work," or "The future of X"
* automatic testimonial, pricing, FAQ, or CTA sections when they do not serve the product
* neon dark-mode styling by default
* hover scaling, bouncing, floating, glowing, or scroll animations that communicate nothing
* fade-up animation on every section
* unnecessary modals
* making every action look like a primary button

Instead, make design decisions based on the actual product, audience, content, and brand.

Before designing, explicitly decide:

1. typography
2. color system
3. shape language
4. spacing/rhythm
5. information hierarchy
6. interaction model
7. motion philosophy

Prefer composition over decoration.

Use whitespace, alignment, typography, scale, imagery, contrast, and deliberate asymmetry before adding containers, shadows, gradients, glows, or effects.

Do not create a component merely because landing pages commonly contain that component. Every section must have a reason to exist.

Vary section composition. Avoid repeating identical card structures down the entire page.

Use real product content whenever possible. Design for realistic long text, missing data, empty states, loading states, errors, mobile layouts, and interaction states—not merely the ideal screenshot.

When finished, perform an "AI slop audit."

Ask:

* Does this resemble the default output of a generic AI website generator?
* Could I swap the logo with an unrelated SaaS company and have the page still work?
* Did I use a visual treatment because it supports the product, or because it looks "modern"?
* Am I using cards where simple layout and typography would work better?
* Are multiple sections using essentially the same layout?
* Is any copy generic enough to describe hundreds of products?
* Is any animation purely decorative?
* Are the typography, palette, and visual language specific enough to create an identity?

If 3 or more recognizable AI-default patterns appear together, redesign that area before completing the work.

The goal is not to make the interface unusual for the sake of being unusual. The goal is for every visible design decision to feel intentional and appropriate to this specific product.
